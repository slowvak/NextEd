<objective>
Add a relative path display to the volume list sidebar so users can see which subfolder each volume lives in.

Purpose: When scanning a directory tree with many subjects, volumes often have identical names. Showing the parent folder path (e.g. "subjects/sub-01/anat") distinguishes them without cluttering the primary name display.
Output: Server populates `relative_path` on `VolumeMetadata`; client renders it as a muted second line when non-empty.
</objective>
